# Лабораторная 5

* С помощью предобученной модели text2img сгенерировать фотографии себя в разном окружении (в стиле киберпанка, из металла, в эльфийском городе и прочее). 
* Показать 5 качественных изображений себя, должно сохраняться портретное сходство.
* Показать изображения, сгенерированные по тексту “<ваш токен> in a forest ”, “<ваш токен> in a city ”, “<ваш токен> in a beach ”, с уточнениями high quality , realism ” или подобные. 
* Показать изображения, сгенерированные по тексту “<ваш пол> in a forest ”, “<ваш пол> in a city ”, “<ваш пол> in a beach ”, с уточнениями high quality , realism ”. Генеративная модель не должна испортится после дообучения и разучиться генерировать других людей.
* Не использовать: трансляцию из изображения в изображение, негативные промпты, API, веб сервисы
* Оценить качество сгенерированных изображений 3 мерами (не FID, IS) и обосновать, почему вы выбрали такие меры.
